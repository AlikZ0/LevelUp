# 🚀 LevelUp

Игровой трекер целей. Выполняй ежедневные действия по своим целям, получай
**очки опыта (XP)** как в игре, прокачивай **уровень** и следи за прогрессом
по календарю. Только фронтенд — никакого сервера, всё хранится прямо в браузере.

🔗 **Живая версия:** https://alikz0.github.io/LevelUp/

## Возможности

- 🎯 **Свои цели** (3-4 и больше) — название, иконка, цвет и XP за выполнение.
- ⭐ **Опыт и уровни** — отметил выполнение → получил XP. Не отметил → XP нет.
  Из общего опыта рассчитывается уровень и звание (Новичок → Легенда → Титан).
- ✅ **Выполнение с подтверждением** — нажимаешь «Отметить выполнение» →
  подтверждаешь в окне → цель засчитывается и **скрывается до завтра** (не висит
  как «выполнено»). Есть короткая отмена в уведомлении, если нажал случайно.
  Счётчик «выполнено за день» и календарь показывают, что прогресс сохранён.
- 🔥 **Серии (стрики)** — сколько дней подряд выполняешь каждую цель.
- 🗓️ **Календарь** — месячная сетка с heat-map по дням. Нажми на любой день,
  чтобы открыть его и **изменить выполнения задним числом**. Подсвечиваются
  сегодня, выбранный день и «идеальные» дни (100%). Итоги за месяц: опыт,
  выполнения, процент от плана, идеальные дни.
- 🚩 **Точка старта** — задаёшь дату начала отслеживания; её можно изменить в
  любой момент. Дни раньше старта заблокированы, навигация за неё не уходит.
- 🏆 **Достижения** — нажми кнопку-кубок на цели, впиши в окне, что именно ты
  выполнил, и сохрани. Цель навсегда переезжает в раздел «Достижения» с датой —
  не исчезает, а остаётся как трофей. Вернуть достижение обратно в активные
  нельзя (до сохранения можно отменить). Достигнутые цели не участвуют в
  ежедневной статистике, но заработанный ими опыт сохраняется.
- ◀▶ **Прошлые дни** — листай стрелками или кликай по календарю и отмечай
  пропущенное.
- 💾 **Хранение локально** — всё автоматически сохраняется в `localStorage`.
- 🎨 **Единый набор SVG-иконок** — аккуратные линейные иконки вместо эмодзи,
  включая кольцевой индикатор прогресса уровня.
- 🌗 **Светлая и тёмная тема** — переключается вручную (выбор запоминается) или
  следует за настройкой системы. Зум по двойному тапу на телефоне отключён.

## Защита от потери данных

Данные важно не потерять, поэтому:

1. **Автосохранение** при каждом действии.
2. **Резервная копия** — перед каждой перезаписью прошлое состояние
   дублируется во второй ключ хранилища.
3. **⬇️ Экспорт** — скачивает файл `levelup-backup-YYYY-MM-DD.json` со всеми
   данными. Храни его где угодно (облако, флешка).
4. **⬆️ Импорт** — восстанавливает данные из скачанного файла на любом
   устройстве или в любом браузере.

> Совет: делай экспорт время от времени — так данные не потеряются, даже если
> очистить браузер или сменить устройство.

## Как запустить

Сборка не нужна — это статические файлы.

- **Локально:** открой `index.html` двойным кликом в браузере.
- **GitHub Pages:** деплой настроен автоматически через GitHub Actions
  (`.github/workflows/deploy-pages.yml`). При каждом push в `main` воркфлоу
  включает Pages и публикует сайт на https://alikz0.github.io/LevelUp/ —
  вручную в настройках ничего трогать не нужно.

## 📲 Установка на телефон (PWA)

Приложение — полноценное PWA: его можно **установить на домашний экран** и
запускать **без интернета**.

- Работает при открытии по **HTTPS** (например, GitHub Pages) или на
  `localhost` — Service Worker требует защищённого соединения.
- **Android / Chrome:** меню «⋮» → «Установить приложение» (или всплывающая
  подсказка).
- **iOS / Safari:** «Поделиться» → «На экран „Домой“».
- После первой загрузки оболочка кэшируется — открытие работает офлайн, а все
  данные и так лежат локально.

## Структура

```
index.html     — разметка, подключение манифеста и регистрация Service Worker
styles.css     — оформление (минимализм, светлая + тёмная темы)
app.js         — логика: цели, опыт, уровни, достижения, календарь, хранилище
manifest.json  — веб-манифест PWA (имя, иконки, цвета, standalone)
sw.js          — Service Worker: network-first (свежая версия при сети) +
                 офлайн-фолбэк из кэша
icons/         — иконки приложения (192/512/maskable + apple-touch-icon)
.github/workflows/deploy-pages.yml — авто-деплой на GitHub Pages
```

Модель данных, которая хранится и экспортируется:

```json
{
  "version": 1,
  "createdAt": "…",
  "startDate": "2026-07-25",
  "goals": [
    { "id": "…", "name": "Спорт", "icon": "dumbbell", "color": "#16a34a", "xp": 15 },
    { "id": "…", "name": "Учёба", "icon": "book", "color": "#4f46e5", "xp": 50,
      "achievedAt": 1753440000000, "achievementTitle": "Выучил React" }
  ],
  "log": { "2026-07-25": { "<goalId>": true } }
}
```

- `icon` — ключ из встроенного набора SVG-иконок.
- `achievedAt` (timestamp) и `achievementTitle` (введённый текст) появляются
  только у целей, отмеченных как достигнутые.

## Как хранится уровень

Уровень **нигде не хранится напрямую** — он всегда **пересчитывается** из истории,
поэтому не может «рассинхрониться» с прогрессом:

1. Из `log` берутся все отмеченные выполнения (начиная с точки старта).
2. Суммируется опыт: за каждое выполнение прибавляется `xp` его цели → **общий XP**.
3. Из общего XP выводится уровень. Порог перехода растёт: L1→L2 = 100 XP,
   L2→L3 = 150, L3→L4 = 200, и далее +50 за уровень.

То есть «сохраняется» не уровень, а факты выполнений — а уровень и звание
считаются на лету при каждой отрисовке.

### Ключи в `localStorage`

| Ключ | Назначение |
| --- | --- |
| `levelup.data.v1` | основные данные (цели, лог, точка старта) |
| `levelup.backup.v1` | **автоматическая резервная копия** — предыдущее состояние перед последней записью; из неё приложение восстановится, если основной ключ повредится |
| `levelup.theme` | выбор темы (`light` / `dark`) |

Поэтому в хранилище видно **два ключа с `v1`** — это не дубликат: `data.v1` это
текущие данные, а `backup.v1` — их страховочная копия. Суффикс `v1` — это версия
формата (чтобы будущие изменения структуры могли использовать `v2`, не затирая
старое).
